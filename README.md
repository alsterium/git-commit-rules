# git-commit-rules

Codex向けのGitコミット運用スキルです。変更の所有権を保護しながら、検証済みの論理単位をConventional Commitsとして安全にコミットします。

## 構成

- `SKILL.md` — スキル本体
- `references/commit-message-policy.md` — コミットメッセージの詳細ポリシー
- `agents/openai.yaml` — スキルの表示名と既定プロンプト

## 利用方法

このリポジトリをCodexのスキルディレクトリへ配置し、`git-commit-rules` スキルを有効にしてください。
